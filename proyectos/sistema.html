01

Sobre el proyecto

Sistema web desarrollado para administrar y organizar el registro de líderes y localidades, permitiendo centralizar la información y facilitar su consulta y gestión desde un panel administrativo.

Mi participación estuvo enfocada en el desarrollo del sistema, trabajando tanto en el frontend como en el backend, la estructura de la base de datos, validaciones y funcionalidades necesarias para administrar los registros.

Desarrollo

Sistema de registros

El sistema fue desarrollado para centralizar la información de líderes y localidades, facilitando la administración de los registros desde una interfaz web.

La aplicación conecta el frontend con una base de datos MySQL mediante PHP, permitiendo registrar, consultar y modificar la información de manera organizada.
